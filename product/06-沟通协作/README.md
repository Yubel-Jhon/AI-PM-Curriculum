# 板块⑥ 沟通协作 · 侧重点：影响力

> 在干什么：推动一群你没有职权的人把事做成——无授权领导。

## 术语清单

| # | 术语 | 一句话 |

## 一句话归纳

沟通协作 = 影响力能力，不是靠权力，是靠专业、靠谱、让人愿意跟你干。

## 改造点（AI）

AI 沟通：对技术讲业务目标与验收口径，对高管讲单位经济，对销售讲使用边界与兜底，对合规讲风险前置。
