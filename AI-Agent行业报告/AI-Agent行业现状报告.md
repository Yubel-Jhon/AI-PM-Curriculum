## 摘要 · 核心观点

- **① 瓶颈迁移**：AI Agent 的核心矛盾已从「模型不够聪明」转向「不够可靠、可控、便宜」。技术能撑起单点场景，但多步成功率、单位经济、责任归属三道坎，让它仍卡在「单点工具」而非「可托付的自主劳动力」。
- **② 市场「框架热、应用冷」**：叙事规模很大（狭义 2024 约 52.6 亿美元、广义 Gartner 2026 约 2019 亿美元），但能收上钱的仍是代码、客服、办公等少数场景；代码是最快商业化跑通的赛道（Claude Code $2.5B ARR、Cursor $4B ARR）。
- **③ 竞争从「模型之争」转向「工具 + 数据闭环之争」**：模型层「Anthropic 能力领先、OpenAI 规模领先、Google 生态领先、DeepSeek 价格领先」；护城河沿产业链向下游的「行业 know-how + 私域数据」迁移。
- **④ 商业化「按调用/按结果付费」为主**：多数通用场景单位经济尚未打正，只有「高频、可量化、容错低」场景（代码/客服）跑通；护城河来自数据飞轮而非算法本身。
- **⑤ 安全合规是「发布门槛」**：提示注入（OWASP LLM01 连续两版第一）与责任归属不清，是 B 端采购的最大隐性阻力。

**投资建议（简版）**：沿「代码 → 客服 → 办公/营销 → 金融/法律」的成熟度顺序，优先布局垂直 Agent 与具备数据飞轮的场景；跟踪模型厂商（OpenAI / Anthropic）与编码/客服两条已跑通商业化路径的龙头。

**风险提示（简版）**：多步可靠性提升不及预期；单位经济长期打不正；提示注入/供应链投毒造成真实损失；监管趋严抬高门槛；同质化竞争价值难沉淀。

## 一、行业复盘与定义

### 1.1 定义与边界

**AI Agent** = 规划（Planning）＋ 工具调用（Tool Use）＋ 记忆（Memory）＋ 自主执行（Autonomy）——不再只是「回答问题」，而是拆解任务、调用工具、循环逼近目标。

与相邻形态是「自主程度 × 任务确定性」连续谱上的落点，而非替代关系：

| 形态 | 核心特征 | 自主程度 | 与 Agent 关系 |
|---|---|---|---|
| Chatbot | 只输出文本 | 无 | 交互底座 |
| Copilot | 人主导、AI 辅助 | 低 | 前置形态 |
| RPA / 工作流 | 规则固定、确定流程 | 中（无理解） | 互补 |
| AI Agent | 自主规划 + 工具 + 循环 | 高（受约束） | 收敛点 |

Agent 专攻 RPA 覆盖不了的非确定任务，二者互补而非竞争。分层上，从「单 Agent → 多 Agent → Agentic Workflow」，自主程度递增、工程复杂度同步上升。

### 1.2 发展历程与复盘

| 时间 | 事件 | 对 Agent 的意义 |
|---|---|---|
| 2022.11 | ChatGPT 发布 | 「大脑」进入大众视野 |
| 2023.06 | OpenAI Function Calling | 工具调用正式 API 化 |
| 2024.09 / 11 | o1 推理模型 / MCP 开源 | 「慢思考」底座 + 工具连接标准化 |
| 2025.01 / 04 | Operator / Google A2A | GUI 操作 + 多智能体互操作协议 |
| 2025.12 | MCP 捐给 Linux 基金会 | 工具调用标准中立治理、「定型」 |
| 2026.04 | Gartner 首发 Hype Cycle | 官方判定 Agentic AI 处「膨胀期顶峰」 |

**复盘结论**：阶段划分为 Copilot（每步人驱动）→ Agent（自主规划 + 工具 + 状态）→ Multi-Agent（多专精协作）。2025H2–2026H1 从「跑马圈地」进入「收敛」——标准定型、框架 1.0 化、编码 Agent 跑通商业模式、监管入场。

## 二、产业链分析

AI Agent 产业链分「上游（算力/芯片 + 基础模型 + 数据）→ 中游（框架/中间件/平台）→ 下游（垂直应用/客户）」三层。利润与收入沿产业链**向下游迁移**，但**算力仍是最大现金池**。

### 2.1 上游：算力 / 芯片 + 基础模型 + 数据

**算力层高度垄断**：Nvidia 数据中心 GPU 份额 80%–90%（按 AI 加速器收入计约 75%–81%），最近财年数据中心收入约 1940 亿美元；AMD 第二梯队（份额 5%–7%），Google TPU / 华为昇腾 / 百度昆仑芯自研追赶。推理已取代训练成为算力增长主引擎——**Agent 每多一次工具调用、多一步推理，都直接放大 token 消耗与 GPU 需求**，这是整条传导链的起点。

**基础模型层「双雄 + 开源围剿 + 中国军团」**：

| 厂商 | 定位 | 商业化状态（2026） |
|---|---|---|
| OpenAI | 闭源通用龙头，下探 Agent 平台 | 年化收入 $40B；企业收入反超消费端；估值 $852B |
| Anthropic | 企业/Agent 能力最强 | ARR $14B→$30B（4 月，一度反超 OpenAI）；Claude Code $2.5B ARR |
| Google | 生态最全、模型追赶 | Gartner/IDC 双 Leader；Cloud 单季 $20.02B（+63%） |
| DeepSeek | 开源「价格屠夫」 | ARR 约 27–34 亿元（九成来自 API）；DeepSWE 12.8→62.7 |
| 智谱 GLM | 「中国 Anthropic」 | 2025 营收 7.24 亿；MaaS ARR 17 亿元（12 个月 60 倍） |
| 通义千问（阿里） | 绑定阿里云 | 通义+百炼 ARR 破 80 亿元（含算力），年底冲 300 亿 |
| 豆包（字节） | 国内「一超」 | ARR 约 $4B（272 亿元）；DAU 2 亿+；火山 MaaS 目标 150 亿 |

**数据层**：未被充分单独定价，但「行业 know-how + 私域数据」是下游应用的核心壁垒；MCP 让数据/工具接入标准化，数据价值更多沉淀在垂直应用层。

### 2.2 中游：框架 / 中间件 / 平台（Agent 的「操作系统层」）

| 平台 | 定位 | 开源/商业 | 融资格局（2026） |
|---|---|---|---|
| LangChain（LangGraph/LangSmith） | 全球主流编排运行时 | 开源 + LangSmith SaaS | Series B $1.25 亿 @ $12.5 亿估值；月下载 9000 万 |
| Microsoft Agent Framework | 合并 AutoGen + Semantic Kernel | MIT 开源，靠 Azure 变现 | 1.0 GA；Azure AI Foundry Agent Service 1 万+ 组织 |
| CrewAI | 多智能体协作 | 开源 + 企业订阅 | 10 万+ 开发者、Fortune 500 跑 14 亿次自动化 |
| Dify | 开源 LLM 应用/Agent 平台 | 开源 + 托管 | Pre-A $3000 万 @ $1.8 亿估值 |
| Coze / 扣子（字节） | 国内最大 Agent 搭建平台 | 免费托管为主 | 扣子 3.0 全平台升级 |
| Copilot Studio（微软） | 企业级低代码 Agent 平台 | 订阅 + credit 计费 | 80%+ Fortune 500 在用；M365 Copilot 3000 万+ 席位 |
| 百度千帆 / 阿里百炼 | 国产 MaaS | 商业 MaaS | 千帆 Q1 AI 收入 136 亿元；百炼与通义打包 ARR 80 亿 |

**中游特征**：薄利润、强网络效应——开源免费是默认选项，变现靠托管、可观测性、企业合规；护城河最弱，随时被上游（OpenAI Frontier）和下游（Copilot Studio 内建 Agent）上下夹击。

### 2.3 下游：垂直应用 / 客户（价值落地的「最后一公里」）

| 场景 | 代表产品与厂商 | 关键数据 |
|---|---|---|
| 代码（最成熟） | Claude Code、Cursor、GitHub Copilot、Codex | 市场约 128 亿美元；CR3 占 70–80% |
| 客服（第二成熟） | Agentforce、Sierra、ServiceNow、Fin、Decagon | Agentforce ARR $1.2B（+205%）；Sierra 估值 $15.8B |
| 办公/通用企业 | M365 Copilot、ChatGPT Work、Gemini Enterprise | Copilot 席位 3000 万+ |
| 营销/销售 | Clay、Apollo AI、11x、Artisan | 融资最多但生产化记录最弱 |
| 金融 | Harvey、Hebbia、Bloomberg AI、Rogo | 资管中等成熟，银行业受监管落地慢 |
| 法律 | Harvey、Spellbook、Robin AI、Ironclad AI | 2025–26 快速成熟 |

### 2.4 传导逻辑

开源模型（DeepSeek/Qwen/Llama）+ 混合路由，使企业 AI token 成本 1 年内下降 67%（$18.40 → $6.07/百万 token）。**上游降价直接打开中游框架和下游应用的毛利空间**；下游定价从「per-seat」转向「per-outcome」（Agentforce 约 $2/对话、微软 credit 计费），反过来又放大上游 token 消耗，形成正反馈闭环。中信证券判断 2026 年部分软件公司 AI 原生应用收入占比将达 10–20%。

## 三、市场规模与测算

### 3.1 口径拆解（画图前必须分清）

AI Agent 市场无统一口径，不同机构数字差 10 倍以上：

- **狭义（软件/平台）**：MarketsandMarkets / GVR / BCC / Omdia，只算 Agent 软件/平台收入 → 2025 约 78–80 亿美元，2030 约 483–526 亿。

## 六、技术现状（透镜⑧：能不能做）

底层模型的三类支撑：**推理**（「慢思考」抬高多步规划与自我修正天花板）、**长上下文**（1M–2M Token 窗口让记忆 + 状态多跑几步）、**多模态**（「看界面、点按钮」，工具调用从 API 扩到 GUI）。

### 6.1 核心能力现状

| 能力 | 现状 | 成熟度 |
|---|---|---|
| 规划 | 简单可用，长程易走偏 | 中 |
| 工具调用 | MCP 标准化后改善，完成率不稳 | 中高 |
| 记忆 | 短期成熟，长期不成熟 | 中低 |
| 反思 | 推理模型带来进步，不保证收敛 | 中 |

### 6.2 关键 Benchmark

![图表10](..\\ppt\\charts\\fig10_osworld.png)

### 6.3 推理成本下降

![图表12](..\\ppt\\charts\\fig12_cost.png)

同级能力输出价从 GPT-4 的 $60 降到 GPT-4o 的 $10（17 个月降 6 倍），输入价降 12 倍；小模型侧 GPT-4o mini 输出 $0.60，相对 GPT-4 降 100 倍。第三方追踪显示「最便宜可用」输出价年均降幅约 90%。

### 6.4 多步任务的成功率衰减（复利误差）

![图表13](..\\ppt\\charts\\fig13_decay.png)

`P(总成功) = (单步成功率)^步数`——单步 90% × 20 步，端到端仅约 12%。这是 Agent「演示惊艳、生产拉胯」的数学根源，也是单位经济打不正的核心技术原因。

**技术瓶颈小结**：幻觉（通用 22%–94%）、多步成功率衰减、长程任务成功率多数 <20%（METR）、多步 p95 延迟 58–90 秒。**判断：单点、封闭、可验证场景「能」；能力与执行已分化——基准快速上升，真实环境端到端慢一个量级。**

## 七、应用落地（透镜⑨：做得好不好）

|---|---|---|---|
| 代码 | Claude Code / Copilot / Cursor / 灵码 | 结果可编译、可测试 | SWE-bench + 采纳率；Claude Code $2.5B ARR |

| 办公 | M365 Copilot / Notion AI | 流程相对确定 | 席位 3000 万+；NHS 日省 43 分钟 |
| 营销 | 万相台 / AgenticOS | ROI 可归因、闭环短 | ROI +20%；获客成本 −34% |
| 金融 | Bloomberg ASKB / 宇信尽调 | 数据密集、人机协同 | 尽调周期 周级→小时级 |

![图表14](..\\ppt\\charts\\fig14_penetration.png)

**仍未跑通的场景**：长程自主任务（METR 实测「0% 无需人工清理即可用」）、高风险决策/执行（以「出事故→上护栏→禁掉」为主）、长记忆/跨系统状态。

**判断**：落地分水岭不是「有没有 AI 价值」，而是「能否建评估集 + 在线指标 + 数据闭环」——评测能力决定落地顺序（透镜⑨）。

## 八、信任、安全与合规（透镜⑩：守住底线）

**三大风险**：① 提示注入（头号，OWASP LLM01 连续两版第一，受控测试凭据外泄 96%）；② 越权/误操作（Agent 继承用户完整权限，缺最小权限控制）；③ MCP 供应链投毒（工具描述中毒平均攻击成功率 36.5%）。

**责任归属**：AI 无法律人格，责任落在部署方/开发方（Air Canada 被判兑现聊天机器人承诺）——「法律不确定、部署方兜底、传统保险退场、专属 AI 险萌芽」。

**监管三地分轨**：中国（双备案 + 内容标识 + 数据出境，已处置违规智能体 3500+ 款）；欧盟（EU AI Act 要求「可审计 + 可兜底 + 可问责」）；美国（联邦轻监管、州法反推、DOJ 刑事执法优先）。

**发布门槛**：业界正从「模型层对齐」转向「环境层强制 + 最小权限 + 人工确认关键动作 + 可审计日志」。Agent 产品经理的第一职责：先想清楚怎么不闯祸，再谈功能多强。

## 九、商业化与经济性（透镜⑪：值不值赚不赚）

**成本结构**：一次 Agent 任务 = 规划 + 多轮工具调用 + 反思 + 重试，Token 消耗放大 5–30x（编码极端 1000x）；主因不是模型贵，而是重试与静默失败。

| 环节 | 现状 | 判断 |
|---|---|---|
| 推理成本 | 同能力 2 年降 80–90% | 被多步放大抵消 |
| 定价建模 | 向按结果付费迁移 | 把风险转给供应商 |
| 付费意愿 | B 端愿付，C 端 71% 只要免费 | 分化大 |
| 数据飞轮 | 代码/客服有，多数没有 | 真正的护城河 |

**核心矛盾**：价值越高（越自主）→ 单次成本越高 → 越难定价 → 越难算清账。单位经济只在「高频、可量化、容错低」场景打正。**选场景即选商业模式，第一性动作是「算账」而非「堆能力」。**

**按结果付费案例**：HubSpot $0.50/解决、Intercom Fin $0.99/解决、Sierra $1.50/解决——护城河来自数据飞轮，不是算法本身。

## 十、趋势判断（12–24 个月）

**高确定性**：① 推理成本持续下降（12 个月再降 40%+），但多步吃掉红利；② 工具调用标准化（MCP/A2A 成事实标准）；③ Agent 嵌入垂直工作流（垂直 CAGR 62.7% > 整体 44.9%）；④ 安全合规前置（可审计、可兜底、分层发布成标配）；⑤「慢思考 + 反思」成默认架构，转向按难度分配算力。

**高分歧/不确定点**：① 多智能体是否必要（默认单 Agent，必要时才多 Agent）；② 是否出现「Agent 平台型超级应用」，入口归属未定；③ 通用 Agent 何时可托付（乐观 2026 底–2027，谨慎半自主）；④ 按结果付费能否主流（混合模式更现实，纯结果短期难）。

## 十一、投资建议

**行业评级：看好（首次覆盖）**。核心逻辑：技术单点可用 + 代码/客服商业模式已跑通 + 成本持续下探，行业处「膨胀期顶峰后的验证期」，结构性机会在「垂直 Agent + 数据飞轮」。

**评级说明**（对标券商体系）：买入（相对指数 +15% 以上）/ 增持（5%–15%）/ 持有（-5%–5%）/ 卖出（-5% 以下）；行业评级：强于大市/中性/弱于大市。本报告为行业层「看好」，不对单一标的给出个股评级。

**按环节关注**：
- **模型/算力层**：OpenAI、Anthropic、Google、Nvidia（算力为最大现金池）。
- **垂直 Agent 层**：Cursor（编码）、Salesforce Agentforce / Sierra / Intercom Fin（客服）——已跑通商业化的两条赛道。
- **国内**：智谱、字节豆包、阿里通义（MaaS 层，尚未跑出 Agent 专属收入大数）。

**三条行动建议**：① 用「评测」倒逼「落地」——先定义评估集与在线指标，评不出的场景先不做（透镜⑨）；② 把「单位经济」当第一过滤器——优先高频、可量化、容错低、有数据飞轮的场景（透镜⑪）；③ 把安全与责任当「发布门槛」——内建权限边界、兜底与可审计（透镜⑩）。

## 十二、风险提示

1. **多步可靠性提升不及预期**：单步成功率衰减是数学约束，若长程任务成功率无法突破，Agent 将长期停留在「单点工具」，与「自主劳动力」的预期背离。
2. **单位经济长期打不正**：多步放大推理成本，若按结果付费无法覆盖重试与静默失败成本，商业化将停滞。
3. **提示注入/供应链投毒造成真实损失**：头号安全威胁无纯模型解，一旦发生重大事故将触发监管收紧与采购观望。
4. **监管趋严抬高门槛**：EU AI Act / 中国双备案若执行加码，将抬高发布成本、拖慢落地节奏。
5. **同质化竞争价值难沉淀**：中游框架供给过剩、开源免费，差异化消失，行业利润被上游（算力）和下游（渠道）两头挤压。
6. **市场空间测算偏差**：市场规模测算基于第三方机构口径与 CAGR 假设，实际发展可能与测算存在偏差（正文标注 [推算]/[估计] 处尤需注意）。
