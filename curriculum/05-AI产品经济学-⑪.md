# ⑪ AI 产品经济学 · 深度详解

> 侧重点：算清「值不值、赚不赚」。AI 功能每次调用都花钱，成本是产品参数，不是后知后觉的账单。
> 面试考的是「能不能从『觉得有用』走到『算得清账』」——单位经济、成本结构、飞轮潜力三件套。

---

## 一、有什么内容（往下走）

### 1. Token / 推理成本 —— AI 产品与传统软件的本质区别

**核心认知**：传统软件的边际成本趋近于 0（多一个用户几乎不多花钱），但 AI 产品**每次请求都有真实成本**（GPU/API token 费）。所以「免费无限用」在 AI 产品上会直接亏穿。

**成本结构（面试要能拆）**：
- 输入 token + 输出 token（输出通常更贵，且用户会反复生成）。
- 模型档位（大模型贵、小模型便宜，差一个数量级）。
- 固定成本：微调、评测、推理基建。

**降本手段（常考）**：缓存（相同问题命中缓存）、小模型先答大模型兜底（模型路由）、Prompt 精简（少塞上下文）、批处理、量化/蒸馏、端侧部署。

---

### 2. 单位经济模型 —— 一句话判断做不做

**公式**：**LTV（用户终身价值）> CAC（获客成本）+ 累计推理成本**。
- 传统产品只看 LTV > CAC；AI 产品多一项「累计推理成本」，因为它是持续发生的。
- 面试话术：「这个功能值不值得做，我算三笔账——用户带来多少价值（LTV）、拉来一个用户花多少（CAC）、他这一生用掉多少 token（累计推理成本）。三笔账算平甚至算赚，才值得做。」

---

### 3. 定价建模 —— 成本打底 + 价值锚定 + 版本分层

**三种主流模式（不是互斥，是分层）**：

| 模式 | 适合谁 | 逻辑 |
|---|---|---|
| API 按量（按 token） | 轻量试用、开发者 | 用多少付多少，引流 |
| SaaS 订阅 | 高频稳定用户 | 按月/年锁定，平滑收入 |
| 私有化部署 | 安全敏感大客户 | 一次性大单，吃安全预算 |

**定价方法**：
- **成本打底**：先算清单次推理成本，价格不能低于它（否则亏）。
- **价值锚定**：按「替用户省了多少钱/赚了多少钱」定价，而不是按成本加成——价值定价能收溢价。
- **版本分层**：免费版引流、Pro 版锁高频、企业版吃大单。

**面试话术**：「定价 = 成本打底 + 价值锚定 + 版本分层。三模式不是互斥是分层：API 引流、订阅锁高频、私有化吃大客户安全预算。」

---

### 4. 模型选型成本权衡 —— 成本/延迟/精度/上下文四维

- 大模型：能力强、泛化好，但贵、慢；小模型（+LoRA）：垂直任务够用、便宜、快、能离线。
- 四维权衡：**成本、延迟、精度、上下文窗口**。复杂推理用大模型，高频/规则明确/延迟敏感用小模型。
- **模型路由**（进阶）：小模型先答，置信度低再升级大模型——成本降一大截，效果不打折。

---

### 5. 数据飞轮与防御性 —— AI 产品真正的护城河

**逻辑**：越用 → 数据越多 → 模型越准/越懂用户 → 用户体验越好 → 用户越多 → 数据更多，形成正循环。

**关键认知（面试高分点）**：AI 产品的护城河**不是算法本身**（算法开源、模型能买），而是**数据飞轮 + 场景数据 + 用户迁移成本**。
- 例：追觅的壁垒 = 硬件性能 × 场景数据 × 端侧模型 × 交互设计，其中「千万家庭真实清洁数据」是稀缺资源。
- 追问「护城河是什么」时，别答「我们的模型很牛」，答「我们的数据飞轮转起来了」。

---

## 二、要做什么（落地动作）

1. **给你想做的 AI 功能算一次单位经济**：LTV、CAC、累计推理成本三个数填进去，看是不是正的。面试「值不值得做」就有真数字了。
2. **背熟一个成本拆解**：输入/输出 token 单价、模型档位差、降本四招（缓存/路由/精简/端侧）。
3. **准备一个定价逻辑**：成本打底 + 价值锚定 + 版本分层，能落到你熟悉的某个产品上。
4. **想清楚一个护城河故事**：你的项目里「数据飞轮」在哪一环转起来了，怎么用数据越用越强。

---

## 三、面试要考什么（真题 + 话术 + 追问链）

**Q1. 这个 AI 功能值不值得做？（业务，高频）**
- 话术：「单位经济 + 成本结构 + 飞轮潜力三件套。先算 LTV > CAC + 累计推理成本吗，再拆成本结构找降本空间，最后看它能不能启动数据飞轮形成护城河。」
- 追问链：怎么降本？（缓存/小模型路由/Prompt 精简/端侧）。

**Q2. API 按量 / SaaS 订阅 / 私有化怎么选？（业务，中频）**
- 话术：「三模式不是互斥是分层：API 引流、订阅锁高频用户、私有化吃大客户安全预算。定价=成本打底+价值锚定+版本分层。」

**Q3. 大模型还是小模型？（概念，高频）**
- 话术：「四维权衡成本/延迟/精度/上下文。垂直高频任务用小模型+LoRA 够用且便宜，复杂推理用大模型。进阶用模型路由：小模型先答、置信度低再上大模型。」

**Q4. 护城河是什么？（业务，高频）**
- 话术：「不是算法（算法开源、模型能买），是数据飞轮 + 场景数据 + 迁移成本。越用数据越多 → 模型越懂用户 → 用户越多，这个循环转起来才是护城河。」

**Q5. 怎么给 AI 功能定价？（业务，中频）**
- 话术：「成本打底（不能低于推理成本）+ 价值锚定（按省了多少钱定价）+ 版本分层（免费引流/Pro 锁高频/企业吃大单）。」

**Q6. 为什么用 coze 不用更先进的工具？（2026 新题，考察成本/选型判断）**
- 话术：「选型不是选『最先进』，是选『匹配需求 + 成本可控 + 团队能维护』。coze 够用、上手快、成本低，先进工具往往贵且复杂，没到那个复杂度不需要上。选型理由是场景和成本，不是『因为不会』。」
