# xmind · 全书总结导图

《产品经理就业知识体系》的思维导图，通过 **Xmind MCP** 生成（云端 fileId `DHcOtLky`），本地这份是等价副本。

## 文件说明

| 文件 | 作用 |
|------|------|
| `产品经理就业知识体系-全书总结.xmind` | 成品，Xmind 打开（3 张 sheet） |
| `板块式全书总结.md` | 源 · sheet1（11 板块直接展开，173 节点） |
| `能力自评清单大表.md` | 源 · sheet2（11 板块 × 侧重点 × 补强，大表） |
| `阶段式学习路径.md` | 源 · sheet3（阶段0-6 学习路径，122 节点） |
| `gen.py` | 生成脚本：读 3 个 .md → 重新生成 .xmind |

## 3 张 sheet

1. **板块式全书总结**（Mind Map）—— 学知识用，每个板块点开就是术语 + 一句话。
2. **能力自评清单大表**（树表）—— 一眼总览，查漏补缺。
3. **阶段式学习路径**（逻辑图）—— 规划进度，阶段0 认知打底 → 阶段6 面试冲刺。

## 怎么改

改内容 → 直接改对应的 `.md` 源文件 → 跑 `python gen.py` 重新生成 `.xmind`。

> `.md` 是可 diff 的源，`.xmind` 是二进制成品。版本记录看 `.md` 的改动最清楚。
