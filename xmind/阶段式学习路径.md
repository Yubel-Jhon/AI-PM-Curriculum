# 产品经理从 0 到就业 · 学习路径（通用打底 → AI 进阶）

## 阶段0 认知打底（第1周）
### 目标
- 建立全景地图，看懂体系全貌
### 学什么
#### 全景知识地图
- 通用底座 ①-⑦（翻译 / 落地 / 交付 / 验证 / 方向 / 影响力 / 底色）
- AI 增补层 ⑧-⑪（能不能做 / 好不好 / 底线 / 赚不赚）
#### 生态隐喻
- 云雨=战略需求 · 河流=项目 · 动植物=团队
- 阳光=商业目标 · 大地=自我修养
#### 通用原则
- 产品 = 用户价值 × 商业价值平衡点
- 听用户的但不要照着做
- 少做就是多做
### 练什么
- 把全景图默画一遍
### 产出
- 能讲给别人听的知识地图

## 阶段1 需求与方案（基本功）
### 目标
- 会翻译需求、会写文档
### 学什么
#### ① 需求能力 · 翻译
- 核心术语：用户需求 vs 产品需求 / 需求采集四象限 / DNA检测·性价比·需求PK / 分·总·分
- 新手学习顺序：先懂用户说的≠他要的 → 再收集四象限 → 再分析 DNA 四步 → 最后排序性价比 → 分总分理清
- 新手怎么上手：听到诉求先问三句 / 先访谈后问卷 / 每条需求走 DNA / 排优先级表、砍需求先砍性价比最低的
- 新手常见坑：把用户说的当需求直接做 / 只发问卷不访谈 / 凭感觉排优先级 / 砍需求手软
#### ② 规划设计 · 落地
- 产品 / 产品经理 / 大产品观
- BRD → MRD → PRD → FSD 文档阶梯
- PRD 七板块写作骨架
### 练什么
- 拿真实反馈还原真实需求
- 按骨架写一份 PRD
### 产出
- 1 份 PRD + 1 个需求分析案例
- 自评 ①② ≥ 3

## 阶段2 执行与验证
### 目标
- 会推进项目、会用数据证明
### 学什么
#### ③ 项目管理 · 交付
- 多快好省 TRQ / WBS / Kick Off
- 三次评审 / 计划与控制
- 做正确的事 vs 正确地做事
#### ④ 数据分析 · 验证
- KPI / 北极星指标
- 漏斗与转化 / 留存活跃
- A/B 测试
### 练什么
- 复盘一个项目（计划与控制口径）
- 拆一个 App 的北极星 + 漏斗
### 产出
- 1 个 STAR 项目故事 + 1 份指标分析
- 自评 ③④ ≥ 3

## 阶段3 视野与影响力
### 目标
- 会判断方向、能推动别人
### 学什么
#### ⑤ 商业战略 · 方向
- 可行性三步曲
- PEST / SWOT
- 价值观 → 使命 → 愿景 → 战略
#### ⑥ 沟通协作 · 影响力
- 无授权领导
- 接口人 / 矩阵型组织
- 管理靠权力，领导靠魅力
### 练什么
- 对一个行业做 PEST + SWOT
- 准备跨部门推动的 STAR 故事
### 产出
- 1 份行业分析 + 1 个影响力故事
- 自评 ⑤⑥ ≥ 3

## 阶段4 底色（贯穿全程）
### 目标
- 明白决定天花板的是什么
### 学什么
#### ⑦ 自我修养 · 底色
- 四件套：爱生活 / 有理想 / 会思考 / 能沟通
- 解决问题通用思路
- 产品经理主义
### 练什么
- 四件套各配一个真实经历
### 产出
- 「为什么是我」的三个真实例子
- 自评 ⑦

## 阶段5 AI 进阶（增量）
### 目标
- 从会做产品 → 会做 AI 产品
### 学什么（按序）
#### ⑧ AI 技术认知 · 能不能做
- 模型能力边界 / RAG
- Agent / MCP / 幻觉缓解
#### ⑨ 模型评估与数据闭环 · 好不好
- 评估集 / F1 / 在线指标
- 数据闭环 / 价值归因
#### ⑩ 信任安全与伦理 · 底线
- 内容安全 / 隐私 / 公平性
- Red Teaming / 发布门槛
#### ⑪ AI 产品经济学 · 赚不赚
- 推理成本 / 单位经济
- 定价建模 / 模型选型 / 数据飞轮
### 练什么
- AI 功能可行性分析（边界 + 幻觉 + 成本）
- 设计评估集 + 在线指标
- 算一个功能的单位经济
### 产出
- 1 个 AI 功能完整案例（可行 → 评估 → 算账）
- 自评 ⑧-⑪ ≥ 3

## 阶段6 面试冲刺
### 目标
- 把学的变成能说出口的
### 学什么
- 附录 B 面试快答 16 题（通用 10 + AI 6）
### 练什么
- 逐题过快答
- 补齐自评 <3 的板块
- 整理作品集（PRD + 项目 + 分析 + AI 案例）
### 产出
- 3 个可讲的案例 + 16 题快答
- 投递面试 · 就业
