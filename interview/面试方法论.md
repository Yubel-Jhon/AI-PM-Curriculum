## 0. 核心结论（3 句话）

1. **AI-PM 面试考的不是背名词，是技术边界认知 + 取舍判断力。** 会背 RAG 定义但说不清「什么场景用 RAG 不用微调」，技术轮必挂。
2. **挂点高度共性**：①只会背不会判断 ②项目经不起「为什么这么决策、数据怎么看」深挖 ③表达没框架没逻辑。
3. **万能答题结构**：概念绑定场景 → 选型给理由 → 风险给兜底。三个环节缺一个就掉分。

## 2. 六大题型 + 破题框架

| 题型 | 识别信号 | 破题框架 | 一句话心法 |
|---|---|---|---|
| **项目题** | 「介绍下你做的项目」 | 背景→目标→职责→关键决策→难点→结果 | 讲「决策和取舍」，不是讲流程 |
| **概念题** | 「什么是 RAG / 幻觉」 | 类比→定义→选型理由→边界→场景举例 | 概念必须绑场景，否则=背名词 |
| **方案/业务题** | 「给豆包设计 XX」 | 红线失败→运营KPI→用户旅程+逃生阀→评测计划 | 先定「绝不能发生什么」 |
| **估算题** | 「估算 ChatGPT 日活」 | 拆解公式→假设→量级校验 | 量级对即可，过程比结果重要 |
| **追问题** | 你答完后继续问「为什么」 | 用「数据/取舍理由/复盘」回，不重复流程 | 追问考的是判断，不是知识 |
| **压力题** | 节奏快、反馈冷、被质疑 | 承认→给依据→转方案，不硬刚 | 被质疑「意气用事」时先接住再给数据 |

## 4. 话术模板库

### 4.1 项目讲述模板（对抗「深挖」）

```
背景：一句话业务背景 + 目标数字
目标：这个项目要解决什么、成功标准是什么
职责：你在里面的具体角色（别用「我们」，用「我」）
关键决策：2-3 个你做的技术/产品取舍（为什么选 RAG 不用微调、为什么这个模型）
难点：最大的困难 + 你怎么定位的 + 怎么解决的
结果：数据（别只说「上线了」，说「采纳率从 X 到 Y」）
```

> 雷区：讲流程不讲决策、用「我们」模糊个人贡献、结果没数据。字节 70%+ 面试含项目深挖，深挖问的全是「为什么这么决策、数据怎么看」。

### 4.2 概念题回答模板

```
1. 类比（一句话，让对方秒懂）：RAG=开卷考试
2. 定义（一句准确的话）
3. 选型理由（什么场景用它/不用它）
4. 边界（它做不到什么）
5. 场景举例（绑一个真实业务）
```

### 4.3 追问接法模板

追问考的是判断不是知识，用三类弹药接：
- **数据**：「这个决策的依据是 XX 指标从 A 变到 B」
- **取舍理由**：「当时在 A 和 B 之间选了 A，因为成本/时间/风险」
- **复盘**：「如果重做，我会先做 XX」

> 雷区：追问时重复上一段流程描述、说「这个我不太清楚」后沉默、被质疑时硬刚。

### 4.4 方案题模板（生成式 AI 产品设计题，来自 Google/Meta/Anthropic 面经）

```
1. 先定义红线失败（什么绝对不能发生）
2. 设运营 KPI（延迟、兜底率、漂移检测频率）
3. 画用户旅程 + 设逃生阀（人工介入点）
4. 提评测计划（A/B 测什么、怎么衡量危害）
```

### 4.5 自我介绍模板（避流水账雷区）

```
60 秒内：一句话定位 → 1 个能说清的项目 → 为什么转/为什么适合 AI-PM → 一句收尾钩子
```
> 雷区（面经实证）：自我介绍讲几分钟流水账直接扣分。

## 5. 总结对比看板

### 5.1 大厂面试风格对比（二手转述，参考）

| 公司 | 风格 | 高频考点 | 典型挂点 |
|---|---|---|---|
| **字节** | 技术深挖、追问密 | RAG 选型、项目决策、数据闭环、竞品（豆包）差异化 | 项目经不起深挖、Function Calling/降级方案答不上 |
| **阿里/蚂蚁** | 压力面、交叉面、HR 权重高 | 微调方式+时间点+基模、效果提升多少、模型路由策略 | 被质疑「意气用事」后崩、HR 面「十动然拒」 |
| **百度** | 偏业务、场景重做题 | 场景+大模型重做一遍、AI 应用自己的思考 | 「一问三不知」、表达没逻辑没亮点 |

> RAG / 微调 / Prompt 三栏对比 → `curriculum/02` §2；幻觉两类来源 → `curriculum/02` §1；离线 vs 在线指标 → `curriculum/03` §2。这些对比表在 curriculum 是唯一来源，本文不再复制。

### 5.5 最容易挂的 5 类人（一手+二手归纳）

1. 只刷题背定义，解释不了技术选型（RAG vs 微调）
2. 简历项目经不起「为什么这么决策、数据怎么看」深挖
3. 表达没框架、自我介绍流水账
4. 对 AI 产品没真实使用体验、只会复述概念
5. 操作失误：主动问「对我的评价」、薪资答不当、简历注水

### 5.7.1 面试官视角红黑榜（新手 ❌ vs 专业 ✅，可直接背）

**AI 产品专属 5 问（来源：一位面试官上午面 6 人复盘）**

| 问题 | ❌ 新手答（被 pass） | ✅ 专业答（要点） |
|---|---|---|
| 怎么判断一个 AI 功能该不该做？ | 「用户有需求不就该做吗」 | 需求只是起点，还要看**技术可行性 + 数据可得性 + ROI + 战略一致性**，否则做「技术能实现但没人买单」的功能 |
| 模型上线后效果不达预期怎么办？ | 「赶紧让算法优化模型」 | 先拆维度定位：准确率还是召回率？badcase 集中还是全差？测试集和真实场景分布一致吗？**带着「问题定位+归因+解决建议」再找算法**，别甩锅 |
| 怎么判断 AI 能力达到上线标准？ | 「算法说准确率 90% 了」 | 90% 是单点指标。还要看：关键场景达标率、badcase 对体验影响、响应延迟、**模型失效的兜底方案**、小流量 A/B 验证。技术指标必须绑业务价值 |
| 和技术团队有分歧怎么办？ | 「听技术的/听老板的」 | 摆出双方观点+依据（你选 A 因需求高频市场大，他选 B 因技术成熟落地快），回到业务目标对齐，不硬刚不甩锅 |
| 常用数据工具和方法？ | 「后台看看 + Excel」 | 神策/GrowingIO 漏斗分析、SQL 提数验证假设、Tableau 搭指标看板、A/B 验证效果。**工具是基础，数据驱动决策思维才是考点** |

**通用 PM 5 问（来源：面试官「听到这几句话基本都 pass」）**

| 问题 | 🚫 淘汰答 | ✔ 加分答（要点） |
|---|---|---|
| 产品经理的价值？ | 「整理需求 + 跟开发沟通」 | 连接用户痛点与商业目标：用户访谈+行为数据挖真实需求，平衡技术可行性与资源，推动共识、敏捷验证，达成增长与商业双赢 |
| 怎么判断功能是否成功？ | 「看用户反馈好不好」 | 多维指标：核心行为数据（使用率/完成度）+ 业务结果（留存/转化）+ 体验指标（满意度/任务时长），再定性访谈还原场景 |
| 技术说需求无法实现？ | 「那就让他们想办法」 | 先理解约束本质（资源/架构/成本），回归问题本质找简化方案或分阶段实施（最小原型验证），保持目标导向不执着单一方案 |

### 5.7.2 讲项目正确打开方式（面试官视角三层法）

> 面试官原话：「我不在乎你原型多炫酷。候选人不是项目经验不够，是**讲项目的方式跑偏了**——追问三轮短板全暴露。」

所有 AI 项目讲法就三层，**多数人只停在第一层**：

1. **功能层**：你实现了什么 AI 能力（识别/生成/推荐），demo 跑通没——「调过接口」层面
2. **设计层**：需求定义、模型选型、数据策略、评估指标怎么定、badcase 怎么分析——「设计过产品」层面
3. **工程与交付层**：系统稳定性、推理延迟优化、线上 badcase 兜底、用户反馈闭环

**模型选型正确讲法**（最高频深挖点）：
- ❌「我用了 GPT-4，效果不错」——信息量为零
- ✅ 讲全链：业务对效果/成本的核心要求 → 怎么评估不同模型（GPT-4/Claude/Llama/国产）在该场景表现 → 准确率/召回/延迟/成本/数据安全怎么权衡 → **为什么大模型不微调** → 评测集怎么构建、badcase 怎么分析 → 上线后效果对比预期、怎么迭代

### 5.7.4 字节两场面经全录（一手）

**面 A：抖音电商 AI 产品（已 oc）——智能客服方向 13 题**

1. 自我介绍 2. 介绍最成功的项目 3. 项目难点 4. **为什么建了向量知识库还要保留 FAQ？** 5. 你具体做了什么 6. **如何构建评测集？** 7. 选什么指标衡量效果 8. **转人工率容易被 mock，怎么处理？** 9. **智能客服如何保证知识时效性？** 10. **微调和 RAG 使用场景区别？** 11. 平时怎么学 AI 知识 12. 为什么离职 13. 对团队的期望

**信号**：智能客服/知识库方向是字节 AI-PM 高频赛道，必考「FAQ vs 向量库」「评测集构建」「转人工率 mock」「知识时效性」四连问——都是 RAG 落地细节，背「切片→召回→重排」不够，要能说清「为什么保留 FAQ、怎么防 mock、知识怎么更新」。

**面 B：字节大模型产品实习——Agent/Skills 方向 11 题**

1. 自我介绍 2. Agent 解决什么问题、怎么做的、最终具备什么能力 3. 你在 Agent 项目里的角色 4. 举一个具体需求例子（内容/实现/交付） 5. 语义理解 badcase 具体是什么、举例用户原输入 vs 误理解 6. 怎么解决 badcase 7. **调 Prompt 时如何确认调好了、评估标准是什么** 8. 服务多个 Agent 时如何评估好坏 9. 调 Prompt 心得 10. **什么场景做思维链（CoT）** 11. **你自己写过 Skills 吗、打算怎么写**

**信号**：Agent 岗必考「badcase 具体化（要举例原输入）」「多 Agent 评估」「CoT 场景」「Skills」——全是 2026 新考点，且要求**举例到用户原输入/误理解的颗粒度**，泛泛而谈必挂。

### 5.7.5 2026 新高频考点（27 届真实拷打实录，必背）

来源：一位 27 届转 AI-PM 连面 9 场的心得，明确「每场必问/几乎必问」的新题：

1. **Agent 是什么？和 workflow 的区别？优缺点？为什么用 workflow 不用 Agent？**（本人最惨烈一次，只会往「规划/执行/记忆/调工具」上凑，被指理论浅薄）
2. **用过什么 AI 工具？对它们的认知？**（考察是否真对 AI 感兴趣——**常备一个万能答案**）
3. **什么是 Skills？让你写 Skills 怎么写？用 AI 生成 Skills 怎么生成？**（万恶的 skills，每场必问）
4. **对 vibe coding 的理解？你亲身做 vibe coding 的感受？**
5. **为什么用 coze 不用更先进的工具？**
6. **龙虾/小龙虾是什么？用过吗？**（几乎必问——**备考时追当下最火的 Agent/Coding 工具**，别只准备去年的）

**备考结论**：Skills、vibe coding、Agent vs Workflow、AI 工具认知这四块是 2026 和往年最大的增量，往年只考 RAG/微调/Prompt，现在往前沿工具和「亲手用 AI 造东西」的体验上移了。没亲手用 Skills/vibe coding 做过东西，很难答出细节。

### 5.7.6 其他公司速览 + 方法论彩蛋

- **AI 独角兽（大模型 PM，一面 mentor + 二面 leader）**：一面 4 题（产品最重要的能力、产品流程、需求定义冲突怎么解决）；二面 4 题（RAG 原理、微调 vs RAG 各自优势、**伦理隐私问题怎么处理**、**数据质量怎么处理**）——伦理+数据质量是二面标配。
- **追觅科技（智能硬件 AI-PM，❌✅ 话术已录）**：核心考「AI 在家庭/商用场景深度落地」的产品逻辑。必考题含「为什么选追觅」「没硬件经验怎么胜任」「具身智能壁垒」「职业规划」——答法全用「理念认同 + 可迁移能力 + 主动补课 + 壁垒=硬件性能×场景数据×端侧模型×交互设计」四段式。
- **百度文心一言（已 offer，0 互联网实习）**：无实习也能上岸，靠「高频使用 ChatGPT/Gemini/Deepseek + 考前做大量对比总结 + 突击大模型原理架构」。**信号：真实 AI 产品使用体验 + 横向对比是 0 经验转行的救命稻草。**
- **5 天速成考点清单**（狠但有用）：①高频考点速记——RAG 链路（召回/重排/向量库选型/切分/上下文）、微调（LoRA 作用/数据构造/评估/过拟合）、Prompt（结构化/Few-shot/CoT/迭代）、评估（准确率/召回/幻觉检测）；②3 道手撕题——AI 交互埋点文档、RAG 效果评估表、微调数据清洗规则；③包装 1 个能打的 AI 项目（说清「核心方案+踩过的坑+解决方法」，逻辑比 demo 重要）。
- **简历包装（转行版）**：功能型 PM 包装成「产品全流程管理+引入 RAG 优化搜索推荐提升准确率 30%」；B/C 端包装成「主动把大模型融入产品（提示词优化客服问答、RAG 整合知识库）」。**一句话：把普通活往「AI 落地 + 数据结果」上靠。**
- **RAG+Rerank 三步**（技术题口径）：见 `curriculum/02` §2（RAG 三步 + Rerank + 切片 + 混合检索的完整落地细节），本文不重复。

## 6. 备考行动清单（按优先级）

1. **挖透一个真实 AI 项目**：选型理由、评估指标、难点+定位过程，写到能经 3 层追问。
2. **背熟 RAG / 幻觉 / 微调选型 / Agent 四个概念的「类比+理由+边界」**，每个绑一个场景。
3. **准备 5 个 AI 产品的真实使用体验**（ChatGPT/Claude/Kimi/豆包），能说清交互逻辑和产品思维。
4. **练方案题框架**：红线失败→KPI→逃生阀→评测计划。
5. **准备 1-2 个「因为伦理/风险叫停项目」的行为故事**（2025 面试新趋势，比「按时上线」故事更吃香）。
6. **补 2026 新考点**：Skills（是什么/怎么写/用 AI 生成）、vibe coding 理解+亲身体验、Agent vs Workflow 区别+选型理由、AI 工具横向认知（常备一个万能答案）——亲手用这些造过 demo，才能答出「举例到用户原输入」的颗粒度。
