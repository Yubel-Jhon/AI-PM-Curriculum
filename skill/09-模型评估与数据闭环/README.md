# 板块⑨ 模型评估与数据闭环 · 侧重点：验证「做得好不好」

> 在干什么：AI 功能上线不是结束，是验证的开始。先定义「怎么算好」，再上线验证，再用数据喂养迭代。

## 术语清单

| # | 术语 | 一句话 |
|---|------|--------|
| 55 | 评估集 / 金标准集 | 人工标注的标准答案，不参与训练 |
| 56 | 离线指标 | 准确率 / 召回率 / F1，评估集上跑 |
| 57 | 在线指标 | 采纳率 / 任务完成率 / 人工接管率 |
| 58 | 数据闭环 | 采集 → 清洗 → 标注 → 评估 → 迭代 |
| 59 | 价值归因 | 判断指标变化到底是模型还是别的因素 |

## 一句话归纳

模型评估与数据闭环 = 验证能力，从「感觉还行」到「有数字证明」。

## 面试怎么考

问「AI 功能怎么验收」→ 先定评估集和离线指标 → 上线看在线指标 → 数据闭环迭代 → 归因到模型。
