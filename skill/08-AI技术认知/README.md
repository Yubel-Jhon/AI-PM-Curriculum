# 板块⑧ AI 技术认知 · 侧重点：判断「能不能做」

> 在干什么：把业务需求翻译成「模型任务」，判断这个功能能不能用 AI 做、用什么模型做、边界在哪。不要求会写代码，要求知道模型的能力上限和翻车点。

## 一句话归纳

AI 技术认知 = 判断能力，把「我有个 AI 想法」变成「这个想法技术上成立、边界在哪」。

## 面试怎么考

给一个 AI 产品 idea，问「能不能做」→ 翻译成模型任务 → 对能力边界 → 判断可行性 + 列风险点（幻觉/延迟/成本）。
