# 板块⑪ AI 产品经济学 · 侧重点：算清「值不值、赚不赚」

> 在干什么：AI 功能每次调用都花钱，成本必须当产品参数管。先算清账，再谈做不做。

## 术语清单

| # | 术语 | 一句话 |
|---|------|--------|
| 66 | Token / 推理成本 | 每次请求都产生真实成本，与传统软件不同 |
| 67 | 单位经济模型 | 收入 − 成本，LTV > CAC + 累计推理成本 |
| 68 | 定价建模 | 成本打底 + 价值锚定 + 版本分层 |
| 69 | 模型选型成本权衡 | 成本 / 延迟 / 精度 / 上下文四维权衡 |
| 70 | 数据飞轮与防御性 | 越用数据越多 → 模型越好 → 用户越多 |

## 一句话归纳

AI 产品经济学 = 算账能力，从「觉得有用」到「算得清赚不赚钱」。

## 面试怎么考

问「这个 AI 功能值不值得做」→ 单位经济 + 成本结构 + 飞轮潜力，三件套。
