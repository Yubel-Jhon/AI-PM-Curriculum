# skill · AI 增补层（skill 相关）

对应《产品经理就业知识体系》中的 **AI 增补层**：板块⑧–⑪。

这是 AI 产品岗位在通用底座之上多出来的必修课，不是孤立知识，而是对 ①–⑤ 的**升级**。

```
⑧ AI 技术认知          → 判断「能不能做」
⑨ 模型评估与数据闭环    → 验证「做得好不好」
⑩ 信任安全与伦理合规    → 守住「底线」
⑪ AI 产品经济学        → 算清「值不值、赚不赚」
```

| 章节 | 侧重点 | 一句话归纳 |
|------|--------|-----------|
| [08 AI 技术认知](08-AI技术认知/README.md) | 判断能不能做 | 把「AI 想法」变成「技术上成立、边界在哪」 |
| [09 模型评估与数据闭环](09-模型评估与数据闭环/README.md) | 验证好不好 | 从「感觉还行」到「有数字证明」 |
| [10 信任安全与伦理合规](10-信任安全与伦理合规/README.md) | 守底线 | 先想清楚怎么不闯祸 |
| [11 AI 产品经济学](11-AI产品经济学/README.md) | 算清账 | 从「觉得有用」到「算得清赚不赚钱」 |
